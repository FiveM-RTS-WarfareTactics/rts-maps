# RTS Maps

Custom map asset streaming for Enyo RTS. Contains desert map models (ydr/ytyp) used for the Mirage battlefield.

## Contents
- `stream/desert_map.ydr` — Custom desert terrain model
- `stream/desert_map.ytyp` — Map type definition

## Install
Place in your `resources/` and add `ensure rts-maps` to `server.cfg` before `enyo-rts`.
